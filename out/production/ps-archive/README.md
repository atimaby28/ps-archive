# 문제 풀이 (Problems)

백준, 프로그래머스 문제 풀이 저장소

---

## 파일명 규칙

- 백준: `BOJ_문제번호_문제이름.java`
- 프로그래머스: `PGS_문제이름.java`
- SQL: `PGS_SQL_문제이름.sql`

## 풀이 헤더

```java
/**
 * 문제: [문제 이름]
 * 링크: [URL]
 * 난이도: [Silver 3 / Gold 4 / Level 2 등]
 * 분류: [BFS, DP, 그리디 등]
 * 풀이 시간: [소요 시간]
 */
```
