# 알고리즘 (Algorithm)

코딩테스트 빈출 알고리즘 13개 정리

---

## 01. 정렬 (Sorting)

| 알고리즘 | 평균 | 최악 | 안정성 |
|----------|------|------|--------|
| 버블 정렬 | O(n²) | O(n²) | ✅ |
| 선택 정렬 | O(n²) | O(n²) | ❌ |
| 삽입 정렬 | O(n²) | O(n²) | ✅ |
| 퀵 정렬 | O(n log n) | O(n²) | ❌ |
| 머지 정렬 | O(n log n) | O(n log n) | ✅ |
| 힙 정렬 | O(n log n) | O(n log n) | ❌ |

- Java: `Arrays.sort()` → 기본형 dual-pivot quicksort, 객체형 TimSort
- 커스텀 정렬: `Comparator` 활용
- 카운팅 정렬: 값 범위가 작을 때 O(n)

---

## 02. 이분탐색 (Binary Search)

**핵심 패턴**
- 기본 이분탐색: 정렬된 배열에서 값 찾기 O(log n)
- Lower Bound: target 이상인 첫 번째 위치
- Upper Bound: target 초과인 첫 번째 위치
- Parametric Search: 조건을 만족하는 최솟값/최댓값 찾기

**코테 포인트**
- "최솟값의 최댓값", "최댓값의 최솟값" → 파라메트릭 서치
- `mid = (left + right) / 2` 오버플로우 주의 → `left + (right - left) / 2`

---

## 03. BFS / DFS

**핵심 패턴**
- BFS: 최단거리, 레벨 탐색 → Queue 사용
- DFS: 경로 탐색, 모든 경우 탐색 → Stack 또는 재귀

**코테 포인트**
- 2D 격자 탐색: `dx[], dy[]` 4방향/8방향
- BFS = 최단거리 보장 (가중치 없는 그래프)
- DFS = 백트래킹, 연결 요소 개수

---

## 04. 그리디 (Greedy)

**핵심 개념**
- 매 순간 최적의 선택 → 전체 최적해
- 정렬 후 탐욕적 선택이 기본 패턴

**대표 유형**
- 회의실 배정 (끝나는 시간 기준 정렬)
- 동전 거스름돈
- 활동 선택 문제
- 구간 스케줄링

---

## 05. 다이나믹 프로그래밍 (DP)

**핵심 개념**
- 최적 부분 구조 + 중복 부분 문제
- Top-Down (메모이제이션) vs Bottom-Up (테이블)

**대표 유형**
- 피보나치, 계단 오르기
- 배낭 문제 (0/1 Knapsack)
- LIS (최장 증가 부분 수열)
- LCS (최장 공통 부분 수열)
- 구간 DP

**코테 포인트**
- 점화식 세우기가 핵심
- 1차원 → 2차원 → 비트마스크 DP 순으로 난이도 상승

---

## 06. 백트래킹 (Backtracking)

**핵심 개념**
- DFS + 가지치기 (pruning)
- 순열, 조합, 부분집합 생성의 기본

**코테 포인트**
- N과 M 시리즈 (백준)로 연습
- `visited[]` 배열 관리 핵심
- 조합: `start` 인덱스로 중복 방지

---

## 07. 재귀 (Recursion)

**핵심 개념**
- Base Case (종료 조건) + Recursive Case (재귀 호출)
- 분할정복: 문제를 작은 부분으로 나눠서 해결

**대표 유형**
- 하노이 탑
- 분할정복 (머지소트, 퀵소트)
- 트리 순회
- 거듭제곱 (분할정복)

**코테 포인트**
- 재귀 깊이 제한 주의 (Java 기본 스택 ~10,000)
- 꼬리 재귀 최적화는 Java에서 미지원 → 반복문 변환 고려

---

## 08. 투 포인터 / 슬라이딩 윈도우

**핵심 개념**
- 투 포인터: 두 포인터가 같은 방향 또는 양 끝에서 이동
- 슬라이딩 윈도우: 고정/가변 크기 윈도우를 이동하며 탐색

**대표 유형**
- 부분합이 K인 구간
- 연속 부분 수열의 합
- 최장 부분 문자열

---

## 09. 최단경로 (Shortest Path)

| 알고리즘 | 시간복잡도 | 음수 간선 | 용도 |
|----------|-----------|----------|------|
| 다익스트라 | O(E log V) | ❌ | 단일 출발점 |
| 벨만-포드 | O(VE) | ✅ | 음수 사이클 감지 |
| 플로이드-워셜 | O(V³) | ✅ | 모든 쌍 최단거리 |

**코테 포인트**
- 가중치 없음 → BFS
- 가중치 양수 → 다익스트라
- 음수 가중치 → 벨만-포드
- 모든 쌍 → 플로이드 (N ≤ 500)

---

## 10. 정수론 (Number Theory)

**핵심 알고리즘**
- 에라토스테네스의 체: O(n log log n) 범위 내 소수 구하기
- 소수 판별: O(√n) 단일 소수 판별
- 유클리드 호제법: GCD O(log n), LCM = a*b/GCD

**코테 포인트**
- 소수 범위 최대 10^7 → 에라토스테네스
- 단일 소수 판별 → √n까지만 확인
- GCD/LCM → 유클리드 호제법

---

## 11. 유니온파인드 (Union-Find / Disjoint Set)

**핵심 개념**
- Find: 루트 노드 찾기 (경로 압축)
- Union: 두 집합 합치기 (랭크 기반)
- 시간복잡도: 거의 O(1) (아커만 역함수)

**코테 포인트**
- 집합 합치기, 같은 집합인지 판별
- 크루스칼 MST에서 사이클 판별
- 네트워크 연결 문제

---

## 12. 최소 신장 트리 (MST)

| 알고리즘 | 시간복잡도 | 방식 |
|----------|-----------|------|
| 크루스칼 | O(E log E) | 간선 정렬 + 유니온파인드 |
| 프림 | O(E log V) | 정점 기반 + 우선순위 큐 |

**코테 포인트**
- 간선 적으면 → 크루스칼 (더 자주 출제)
- 간선 많으면 → 프림

---

## 13. 위상정렬 (Topological Sort)

**핵심 개념**
- DAG(방향 비순환 그래프)에서 선후관계 정렬
- BFS 방식 (Kahn's Algorithm): 진입차수 0인 노드부터

**코테 포인트**
- 선수과목, 작업 순서 문제
- 사이클 존재 → 위상정렬 불가
